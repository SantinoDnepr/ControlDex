# ControlDex

Неофициальное Android-приложение для управления стримером **Widex COM-DEX** и подключёнными к нему слуховыми аппаратами.
Протокол получен реверс-инжинирингом официального приложения COM-DEX 1.3.0 (`com.widex.comdex`).

> ControlDex не связан с Widex A/S и не одобрен ею. Widex и COM-DEX — торговые марки их владельцев. Используйте на свой риск.

Текущая версия: **0.9** (`versionCode 9`), пакет `ua.controldex`, Android 8.0+ (minSdk 26, targetSdk 34).

## Причины написания этой програмы

1. Приложение Com dex разработчики удалили из Google Play market. Все их другие приложение, от Widex - не работают с блютус приставкой Com dex 427. Ситуация, когда железка есть, а программы нет, потому что разработчикам так захотелось. Неприятная, честно говоря.
2. Отсутствие хоть какой документации по Com dex 427. Команды, режимы, включение, настройки - ничего.
3. При каждом подключении оригинальная программа Com dex требует включения геолокации. Вот зачем она им? Чтобы что? Раздражает.
4. Индикатор уровня заряда акумулятора Com dex запихнут в такой дальний угол, что возникает вопрос, а кто вообще писал это ПО? Он вообще в курсе про требования, тенденции современных приложений для смартфонов? Грустно это.
5. Интерфейс програмы. Когда на главном экране находятся всего 2 кнопки - это ужас.

## Возможности

- **Громкость** слуховых аппаратов: `+` / `−` (с автоповтором при удержании) и Mute.
- **Программы**: следующая программа, переключение Normal / Zen+.
- **Фокус** микрофонов: центр, вперёд, назад, влево, вправо.
- **Boost COM-DEX media volume** (нужна прошивка COM-DEX ≥ 1.2.51).
- **Микрофоны слуховых аппаратов** во время трансляции (звонок, музыка, Remote Mic): включить / выключить.
- **Состояние**: батарея COM-DEX и зарядка, neck loop, текущий профиль (Idle / звонок / музыка / Remote Mic), прошивка, серийный номер.
- **Работа в фоне**: foreground-сервис с уведомлением в шторке включается кнопкой «Під'єднатись» и выключается кнопкой «Від'єднатись» (она есть и в самом уведомлении). Автоподключение к последнему COM-DEX при запуске (без работы в фоне и без уведомления) и автоматическое переподключение после потери связи.
- **Режим Green** (по умолчанию): GATT поверх уже существующего классического Bluetooth-соединения (BR/EDR), как скрытый режим оригинала для «проблемных» телефонов. Устраняет заикание звука при старте музыки на Redmi и подобных.
- **Темы**: светлая, тёмная, системная.
- **Встроенная справка** (тексты из оригинального приложения) и экран «Про програму».
- **Диагностика** (включается в настройках): журнал событий GATT/A2DP/HFP, запись в файл, копирование и отправка журнала zip-архивом.

Интерфейс приложения — на украинском языке.

## Как это работает

```
Телефон ──Classic BT (A2DP + HFP, звук; пара создаётся в настройках Android)──► COM-DEX
Телефон ──GATT (управление, ControlDex)───────────────────────────────────────► COM-DEX
COM-DEX ──собственный радиоканал 2,4 ГГц─────────────────────────────────────► слуховые аппараты
```

Телефон не управляет слуховыми аппаратами напрямую: ControlDex пишет команды «пульта» в характеристику COM-DEX,
а тот передаёт их аппаратам. Шифрования и аутентификации на уровне приложения в протоколе нет.

Основное:

| Что | UUID / значение |
|---|---|
| Сервис Widex | `95986f2d-d705-4421-9890-2d32bff70000` |
| `MICROPHONE_CONTROL` | `…70003`, `1` вкл / `0` выкл |
| `NECKLOOP_STATUS` | `…70004`, `0` открыт / `1` закрыт |
| `CURRENT_PROFILE` | `…70005`, `0` нет связи, `1` Idle, `2` HFP, `3` A2DP, `4` Remote Mic |
| `CHARGING_STATUS` | `…70007` |
| `PI_COMMAND` | `…70100`, кадры команд громкости/программ/фокуса |
| `BOOST_MEDIA_VOLUME` | `…70202`, `2` вкл / `0` выкл |
| Батарея, Device Information | стандартные `180F` / `180A` |

Кадры `PI_COMMAND` заканчиваются двумя байтами контрольной суммы с неизвестным алгоритмом, поэтому используются
только готовые кадры из оригинального приложения (см. `ComDex.kt`). Полное описание профиля, последовательности
подключения и открытых вопросов — в техзадании `../TZ_COM-DEX.md`.

## Структура исходников

`app/src/main/java/ua/controldex/`:

| Файл | Назначение |
|---|---|
| `ComDex.kt` | GATT-профиль COM-DEX: UUID характеристик и кадры `PI_COMMAND` |
| `GattClient.kt` | Подключение (BLE и Green/BR/EDR), очередь GATT-операций, нотификации, переподключение, watchdog |
| `Core.kt` | Состояние приложения на всё время жизни процесса: GATT-клиент, последние значения, журнал, автоподключение |
| `ComDexService.kt` | Foreground-сервис (`connectedDevice`) с уведомлением, не даёт системе убить процесс; работает от «Під'єднатись» до «Від'єднатись» |
| `MainActivity.kt` | Главный экран: подключение, громкость, программы, фокус, Boost, микрофоны, состояние, панель отладки |
| `PageActivity.kt` | Экраны «Про програму», «Налаштування», «Довідка» |
| `HelpTexts.kt` | Тексты справки |
| `BatteryView.kt` | Индикатор батареи |
| `FileLog.kt`, `LogProvider.kt` | Журнал в файл и выдача zip-архива через `ContentProvider` |
| `Ui.kt` | Общие настройки (SharedPreferences), тема, версия |

## Сборка

### GitHub Actions

Workflow `.github/workflows/build.yml` собирает `assembleRelease` (JDK 17, Gradle 8.7) на каждый push и выкладывает
`ControlDex.apk` как артефакт `ControlDex-v0.9-release-build<N>`.

Для стабильной подписи (чтобы новые версии ставились поверх старых) задайте секреты репозитория:

| Секрет | Содержимое |
|---|---|
| `KEYSTORE_BASE64` | keystore в base64 |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | алиас ключа |
| `KEY_PASSWORD` | пароль ключа |

Без `KEYSTORE_BASE64` APK подписывается временным debug-ключем (в логе будет предупреждение).

### Локально

Нужны JDK 17, Android SDK (platform 34, build-tools 34.0.0) и Gradle. Android Studio не обязательна.

```powershell
"sdk.dir=D:/Android/Sdk" | Out-File -Encoding ascii local.properties
gradle assembleRelease
```

Результат: `app/build/outputs/apk/release/ControlDex.apk`. Подробная пошаговая инструкция для Windows
(установка JDK, SDK, Gradle, установка на Redmi через `adb`) — в [BUILD_LOCAL.md](BUILD_LOCAL.md).

Локальная подпись тем же ключом, что и в CI: задайте переменные окружения `SIGNING_KEYSTORE`,
`SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`.

## Первый запуск

1. Спарьте COM-DEX в системных настройках Bluetooth: откройте и закройте neck loop, выберите устройство с именем `COM-DEX`.
2. Запустите ControlDex, нажмите «Під'єднатись» и разрешите доступ к «Устройствам поблизости». В шторке появится уведомление —
   это работа в фоне; «Від'єднатись» её останавливает и убирает уведомление.
3. На Xiaomi/Redmi (MIUI) в «Налаштування» приложения отключите оптимизацию батареи и включите автозапуск —
   иначе система может разрывать соединение в фоне.

Пока neck loop открыт или COM-DEX заряжается, управление недоступно, отображается только состояние.

## Диагностика

1. «Налаштування» → включить «Налагодження».
2. На главном экране появятся кнопки «Оновити стан COM-DEX», журнал и «Поділитися (zip)».
3. Через `adb`: `adb logcat | Select-String -Pattern "ControlDex|Bluetooth"`.

## Ограничения

- Читается батарея самого COM-DEX; заряд слуховых аппаратов протокол не отдаёт.
- Новые команды `PI_COMMAND` сформировать нельзя (алгоритм контрольной суммы не раскрыт).
- Приложение не создаёт пару с устройством: сопряжение выполняется в системных настройках Bluetooth.
